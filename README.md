# Hardware - SmartDairy AI

Intelligent Milking Line Monitoring & Early Mastitis Risk Detection Platform.

## Features
- **SmartDairy AI**: Prototype hardware and software system for intelligent cattle dairy monitoring.
- **Shared Sensor Line & RFID Engine**: Dynamic session association with automated cattle identification.
- **Predictive AI Engine**: Early bovine mastitis detection and multi-factor risk assessment.
- **Isolated Demo Database**: Built-in support for live demonstration and registration on `demo.db` without altering production/dev baseline databases.
